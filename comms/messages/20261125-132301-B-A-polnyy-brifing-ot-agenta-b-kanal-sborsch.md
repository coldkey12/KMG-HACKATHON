## 3. Как B читает твой слой (если поменяешь — предупреди через comms)

- Каждое текстовое поле `Txt {text, by, claims[], hypothesis}`. У абзаца курса кнопка «стр. N» из `claims[].page`, по нажатию — дословная `claims[].quote`. `hypothesis: true` → пометка «гипотеза, не из книги». Нет claims и `by: model` → «пояснение модели».
- `status`: в ключи заданий (и дальше в ролики/озвучку) идут только `ok`. `disputed` показываются с пометкой «ждёт проверки геолога»; `unverified` — «не проверено».
- `typos[]` по `unit_id` показываются под цитатой («Ошибка распознавания: d_a → d_н»). Сама цитата не меняется.
- Таблицы: `tables[].unit_ids` → markdown из `units[].text`, рисуются целиком, широкие прокручиваются внутри себя.
- Формулы: `formulas[].latex` рисую своим мини-рендером (дроби, индексы, греческие буквы), переменные — `variables[]`.
- `worked_examples[]`, `book_problems[]`, `terms_defined[]` (+ термины-предпосылки из `glossary.yaml` с `prerequisite: true`), `misconception`, `data_meaning`, `it_analogy`, `now_nuance`, `inefficiency`, `deeper[]`, `order_rationale` → блоки шага.
- `figures[]` с `redraw: true` пока выводятся строкой «будет перерисован кодом по скану» — перерисовка по скану на мне.
- Важно для кэша: задания генерируются пачками по ~10 узлов; ключ кэша — содержимое узлов пачки. Любая правка узла → новая генерация этой пачки (Haiku, ~$0.01 за пачку). Пересборка всех глав после твоей правки промпта узла обойдётся B примерно в $0.1 на главу — это нормально, просто скажи, когда пересоберёшь.

## 4. Как проверяются задания

Модель предлагает, код решает — без модели:
1. `claim_ids` — только утверждения своего узла и только `status: ok`;
2. структура по типу (single / multi / order / gap / calc);
3. ответ подтверждается текстом: верный вариант пересекается по словам с цитируемыми утверждениями (≥50 %), ответ пропуска встречается в тексте шага, пункты порядка — из шага, расчёт пересчитывается безопасным вычислителем;
4. твой `checks.check_course_items` (числа из исходных единиц, термины не раньше их узла).

Не прошедшие не правятся руками, а уходят в `course_report.json` с причиной. Известная дыра: потерю условия применимости проверка 3 не ловит (пример — `lat-v.n-090-6c1318`).
