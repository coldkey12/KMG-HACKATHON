1. Проход «дыр»: предложения автора без опоры в утверждениях узла находятся без модели и дописываются отдельным дешёвым вызовом.
2. Условие применимости — обязательно и в цитате, и в тексте утверждения (запрос B; это же тип закладки ТЗ).
3. Повторный замер теми же метриками на всех шести главах.
