# HANDOFF: между агентами A и B

## A → B: контракт и образец слоя (2026-11-25)

**Готово:**
- Контракт слоя v0.1.0: `contract/layer.schema.json`, описание и соответствие блокам страницы шага — `contract/README.md`.
- Образец, собранный конвейером (не руками): `out/lat-v-sample/layer.json` — Латышова, гл. V, первые 8 узлов плана
  (§17–18: задачи ГИС, типы разрезов и коллекторов, буровой раствор, водоотдача). `chapter.scope = "sample"`:
  в слое только единицы, покрытые этими узлами. Все проверки пройдены: `out/lat-v-sample/checks.md`.
- Полный слой главы будет в `out/lat-v/layer.json` (тот же контракт).

**Чего в образце нет** (появится в полном слое `out/lat-v/`): разобранных примеров (`worked_examples`), формул,
таблиц книги, рисунков с `redraw`. Структура этих полей — в схеме; можно делать вёрстку по схеме уже сейчас.

**Важно для сборщика курса:**
1. Каждое текстовое поле — `{text, by, claims[], hypothesis}`. «стр. N» берётся из `claims[].page`, цитата — `claims[].quote`.
2. `hypothesis: true` — показывать с пометкой «гипотеза / не из книги»; в ролик как факт не брать.
3. В ролик, озвучку и ключи заданий — только утверждения со `status: "ok"`. `disputed` ждут ответа геолога (`open_questions[]`).
4. Таблицы книги — `tables[].unit_ids` → текст в `units[]` (markdown); исправления распознавания — `typos[]` (показывать пометкой).
5. Формат узла и шаблон сцены — `format.format`, `format.scene_template`, `format.state_model`. Названия шаблонов — предложение A
   (см. ниже); если B заведёт свой реестр `scenes/registry.json` (`{"templates":[{"id": "..."}]}`), маршрутизатор будет
   ставить только шаблоны из него, остальное — «нужен новый».
6. Порядок шагов — `nodes[].order`; части — `parts[]`, `nodes[].part_id`; карта связей — `nodes[].links[]`.

**Проверка текста курса** (цитаты, числа, порядок терминов) — без модели:

```
python -m kmg check-text out/<глава>/layer.json <items.json>
```

`items.json` — список `{"node_id", "where", "text", "quote"?, "unit_id"?}` (текст шага, ключ задания, фраза сценария…).
Числа в `text` должны стоять в исходных единицах узла; `quote` — дословно; термины — не раньше узла, где объяснены.
Код выхода 0 — пройдено; отчёт пишется рядом (`*.checks.md`).

**Предлагаемые шаблоны сцен** (владелец — B; `config/routing.yaml`, раздел `scene_templates`):
`tool_in_well`, `radial_profile`, `log_panel_decision`, `crossplot_regions`, `pressure_diffusion`, `growth_timeline`,
`geometry_3d`, `feature_matching` — с моделью состояния для каждого.
