Конвейер, который не выдумывает за автора

Глава книги → учебный слой → курс, задания, сцены и ролики. Каждое утверждение привязано к странице и дословной цитате, и это проверяет код, а не модель.

Листать: стрелки ↓ ↑ или пробел.

01 · Принцип

Модель предлагает, код решает

Один источник правдыКурс, задания, сцены и ролики собираются только из учебного слоя, не из книги напрямую. Правка факта в слое меняет всё, что на нём стоит.
Проверка без моделиЦитата находится на указанной странице. Каждое число есть в исходной единице главы. Термин не встречается раньше своего узла. Таблица покрытия без дыр.
Спорное не идёт дальшеУтверждение, которое не подтвердилось, помечается и не попадает в ключи заданий, сценарии и ролики.

08 · Пересборка

Меняем число в слое — оно меняется на странице

.venv/bin/python -m kmg_course build out/lat-v/layer.json --reuse-tasks
  • Страница шага строится из слоя без модели, около 1 секунды.
  • Задания изменённого узла снимаются: их ключ больше не подтверждён слоем.
  • Полная сборка без флага создаёт для узла новые задания; команда refresh пересобирает и ролик.
09 · Что забирает компания

Модули, которые работают по отдельности

Глава → слойв схеме организаторов, с таблицей покрытия и маршрутизацией.
Модуль проверкипринимает чужой пакет: утверждения, сценарии, спецификации, кадры.
Слой → курс и роликишаблоны сцен с моделью состояния, паспорта по схеме.

Ограничения, о которых мы знаем: сверка со сканами страниц не сделана, поэтому часть утверждений помечена «ждёт проверки»; шаблонов сцен для рифов, дельт и бурения нет; запуск проверен на macOS.
