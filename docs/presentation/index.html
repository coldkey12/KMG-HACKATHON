Курс из главы книги, без выдумок

Программа берёт главу учебника по геологии и сама делает из неё курс для новичка: уроки, задания, анимации и ролики. Каждая фраза курса подтверждена цитатой из книги с номером страницы. Это проверяет обычная программа, а не нейросеть.

Дон Владимир · Темирлан Тойгонбаев

01 / Принцип

Нейросеть пишет, программа проверяет

AКнига читается один разНейросеть разбирает главу на отдельные утверждения. К каждому прикладывает цитату автора и номер страницы. Этот разбор мы называем учебным слоем.
BКаждое утверждение сверяется с книгойПрограмма без нейросети ищет цитату на указанной странице, а каждое число — в том же абзаце книги. Не нашла — утверждение помечается как спорное.
CКурс собирается только из проверенногоУроки, задания и ролики берут текст из этих утверждений, а не из книги заново. Спорные туда не попадают. Исправили факт в одном месте — он меняется везде.

05 / Ролики

Картинку рисует программа, а не нейросеть

Что считаетсяВолна давления — решение уравнения из главы. Кривые приборов — из таблицы признаков книги. Одно описание сцены даёт и анимацию в уроке, и видеофайл.
Что проверяется до записиКаждая фраза диктора ссылается на утверждение из книги. Сцена сверяется с правилами физики. Готовую озвучку программа распознаёт обратно в текст и сравнивает со сценарием: расхождение 2–8% при допустимых 10%.

  • Полная сборка создаёт новые задания; команда refresh пересобирает и ролик.

11 / Что забирает компания

Три части, которые работают по отдельности

01Глава → проверенные утвержденияв формате организаторов, с отчётом о том, что ничего не пропущено.
02Проверка чужих материаловнаходит ошибки в чужих текстах, сценариях и кадрах.
03Утверждения → курс и роликиготовые сцены, которые считаются по формулам.

Что не сделано: рисунки книги со сканами страниц не сверяются, поэтому часть утверждений помечена «ждёт проверки»; готовых сцен для рифов, дельт и бурения нет; запуск проверен только на macOS.
