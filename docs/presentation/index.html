Конвейер, который не выдумывает за автора

Глава книги → учебный слой → курс, задания, сцены и ролики. Каждое утверждение привязано к странице и дословной цитате, и это проверяет код, а не модель.

01 / Принцип

Модель предлагает, код решает

AОдин источник правдыКурс, задания, сцены и ролики собираются только из учебного слоя, не из книги напрямую. Правка факта в слое меняет всё, что на нём стоит.
BПроверка без моделиЦитата находится на указанной странице. Каждое число есть в исходной единице главы. Термин не встречается раньше своего узла. Таблица покрытия без дыр.
CСпорное не идёт дальшеУтверждение, которое не подтвердилось, помечается и не попадает в ключи заданий, сценарии и ролики.

05 / Ролики

Одна спецификация сцены: интерактив и mp4

Что вычисляетсяВолна давления — из решения уравнения пьезопроводности. Каротажный планшет — из таблицы признаков книги. Зона проникновения — по формуле Арчи. Генерации изображений нет.
Что проверяется до рендераКаждая фраза закадра ссылается на утверждение узла. Инварианты сцены — по чек-листу физики. Готовая дорожка распознаётся и сверяется со сценарием: 2–8% ошибок при пороге 10%.

09 / Пересборка

Меняем число в слое — оно меняется на странице

  • Страница шага строится из слоя без модели, около 1 секунды.
  • Задания изменённого узла снимаются: их ключ больше не подтверждён слоем.
  • Полная сборка без флага создаёт для узла новые задания; команда refresh пересобирает и ролик.

10 / Что забирает компания

Модули, которые работают по отдельности

01Глава → слойв схеме организаторов, с таблицей покрытия и маршрутизацией.
02Модуль проверкипринимает чужой пакет: утверждения, сценарии, спецификации, кадры.
03Слой → курс и роликишаблоны сцен с моделью состояния, паспорта по схеме.

Ограничения, о которых мы знаем: сверка со сканами страниц не сделана, поэтому часть утверждений помечена «ждёт проверки»; шаблонов сцен для рифов, дельт и бурения нет; запуск проверен на macOS.
