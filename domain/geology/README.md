# Доменный пакет «geology»

Всё предметное, что использует конвейер. Код конвейера геологии не знает: для нового домена (например, бурения)
копируется эта папка в `domain/<имя>/` и правятся файлы; в конфиге главы меняется `domain_pack`.

| Файл | Что | Кто использует |
|---|---|---|
| `difficulty_types.yaml` | 8 типов трудности (коды из ТЗ, расшифровки — временные) | структурирование, маршрутизация |
| `misconceptions.yaml` | заблуждения из ТЗ с id | узлы (`misconception.pack_id`), модуль проверки |
| `physics_checklist.yaml` | чек-лист физики из ТЗ | модуль проверки, инварианты сцен B |
| `glossary.yaml` | глоссарий RU/EN + термины-предпосылки (считаются известными до главы) | проверка порядка терминов, курс |
| `it_bridges.yaml` | ИТ-мосты: аналогии с границей применимости | узлы (`it_analogy.pack_id`) |
| `pronunciation.yaml` | словарь ударений и чтения обозначений | озвучка B |
| `styleguide.yaml` | легенда цветов и конвенции | курс и сцены B |
| `now_practice.yaml` | «как сейчас» для устаревшей техники (гипотезы, требуют подтверждения геолога) | узлы (`now_nuance`) |
