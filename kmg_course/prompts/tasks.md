Ты составляешь задания к учебному курсу для новичков без геологического образования (сотрудники цифровой трансформации нефтегазовой компании). Курс собран по главе книги; ниже — шаги курса с утверждениями, которые проверены по книге.

Правила — жёсткие, задание с нарушением будет выброшено автоматически:

1. Верный ответ каждого задания следует из утверждений шага (поле `claims`). Ничего не добавляй от себя: ни фактов, ни чисел, ни терминов, которых нет в шаге.
2. У каждого задания `claim_ids` — id утверждений, на которых держится верный ответ (только из этого шага).
3. Числа в формулировке, вариантах и пояснении — только те, что есть в утверждениях шага, и в тех же единицах.
4. Не используй термины из списка `forbidden_terms` шага: они объясняются в курсе позже.
5. Неверные варианты правдоподобны для новичка, но по тексту шага однозначно неверны. Не делай «все перечисленное» и «ни одно из перечисленного».
6. Пояснение (`explanation`) — одна фраза до 20 слов: почему верный ответ верный, со ссылкой на смысл утверждения.
7. Формулировки короткие, фразы до 20 слов. Хорошо работают задания вида «найди, почему…» и «проверь утверждение по книге».

Типы заданий:

- `single` — один верный ответ: `options` (3–4 строки), `answer` — индекс верного (с 0).
- `multiple` — несколько верных: `options` (4–5 строк), `answer` — список индексов (не меньше 2 и не все).
- `order` — расставить по порядку: `items` — 3–5 строк уже в верном порядке. Только если в шаге есть последовательность (порядок действий, цепочка «причина → следствие», от меньшего к большему).
- `gap` — пропуск в тексте: `prompt` — фраза с ровно одним `___`; `answer` — пропущенное слово или короткое словосочетание, дословно как в утверждении шага; `accept` — допустимые варианты написания (можно пустой список).
- `calc` — расчёт: только если в шаге есть формула или правило с числами. `calc`: `{"expr": "выражение на Python с переменными", "vars": {"имя": число}, "unit": "единица", "tolerance": 0.01}`; `answer` — число, равное значению выражения.

У каждого задания `kind` — что оно проверяет: `recall` (узнать факт из шага), `understanding` (объяснить, почему так), `transfer` (применить правило шага к новому случаю из тех же утверждений), `data` (как это выглядит в данных: признаки → правило → вывод). Старайся, чтобы на главу были задания всех четырёх видов, но не жертвуй правилами 1–3.

Сколько: по 2 задания на шаг (на шаг с богатым материалом — 3). Всего не меньше {min_total}. Используй не меньше четырёх типов из пяти; если в главе нет чисел для `calc`, обязательно используй остальные четыре.

Ответ — только JSON без пояснений:

```
{"tasks": [{"node_id": "...", "claim_ids": ["..."], "type": "single", "prompt": "...", "options": ["...", "..."], "answer": 0, "explanation": "...", "kind": "understanding"}]}
```
