Спецификация сцены

Модель состояния. Синтетическая скважина: породы — строки таблицы признаков книги, которые цитирует узел, между коллекторами — глина. Каждая кривая — уровень из ячейки таблицы (минимальные → средние → максимальные; диаметр — меньше/равен/больше номинального), «То же» = ячейка выше, «—» = нет данных. Решение: строки, неразличимые по первой кривой, и кривые, которые их различают, вычисляются из той же таблицы.

Объекты: литологическая колонка (сначала скрыта); шкала глубины, растёт вниз; дорожки кривых по колонкам таблицы; подсветка неразличимых интервалов; панель решения «признаки → вывод».

Параметры: {}.

Допущения:

  • кривые качественные: уровни таблицы признаков, а не измерения конкретной скважины
  • мощности пластов и глубины условные
  • буровой раствор — тот, для которого составлена таблица книги
  • переходных разностей пород нет: каждый пласт — ясно выраженный тип из таблицы

Инварианты (проверены до рендера):

  • ✓ глубина растёт вниз, пласты идут по порядку без перекрытий
  • ✓ одна и та же порода даёт одинаковые показания во всех своих интервалах (кривые из одной таблицы)
  • ✓ подсвеченные интервалы неразличимы по первой кривой (это и есть вопрос ролика)
  • ✓ кривые с меткой «различает» действительно дают разные уровни у подсвеченных интервалов

Мост «где здесь данные и ИТ»

  • Вход: Уровень сопротивления пласта (методы сопротивления): низкое, среднее или минимальное.
  • Вход: Кривая СП: максимальный, минимальный или как в глинах.
  • Вход: Кавернограмма: диаметр скважины больше, меньше или равен номинальному.
  • Вход: Микрозонды: совпадают ли показания для разной длины.
  • Вход: Гамма-метод и нейтронные методы: их уровни (максимальные, средние, минимальные).
  • Выход: Класс породы или флюида по строке таблицы: глина, песок с солёной водой, нефтяной или пресноводный песок, газонасыщенный песок.
  • Где ломается: Нефтяной и пресноводный песок по сопротивлению не различаются.
  • Где ломается: Колонка зоны проникновения для нефти записана неоднозначно.
  • Где ломается: Таблица верна только для глинистого раствора и для наиболее ясных типов пород.
  • ИТ-аналогия (гипотеза модели, не звучит в ролике): Таблица работает как набор правил классификации: каждый признак по отдельности не решает задачу, класс определяется сочетанием признаков. — Признаки ГИС связаны одной средой (раствором и зоной проникновения), они не независимы, как разные фичи. Таблица не даёт весов признакам. Гипотеза, не из главы.
